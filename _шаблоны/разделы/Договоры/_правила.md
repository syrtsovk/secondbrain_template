# Раздел «Договоры» — как ведётся

## Что здесь лежит
Один файл на один документ: договор, допсоглашение, коммерческое предложение, счёт с условиями. Сам документ (pdf/docx) — в `Сырьё/Файлы/`, карточка ссылается на него. {{уточнение человека}}

## Карточка
Имя файла — `ГГГГ-ММ-ДД тип контрагент.md`: `2026-09-01 договор ООО Ромашка.md`. Обязательные поля: **контрагент · тип · номер и дата · предмет · сумма и условия оплаты · срок · статус · где оригинал**.

Статусы: `черновик` → `на согласовании` → `подписан` → `исполнен` / `расторгнут`. КП: `отправлено` → `принято` / `отклонено` / `без ответа`.

## Когда обновлять
При каждом движении по документу: отправили, подписали, оплатили, продлили. Условия, названные вслух на созвоне, — в карточку с пометкой «устно, {{дата}}, {{кто}}» до появления бумаги.

## Шаблоны документов
Свои шаблоны договоров и КП кладутся в `Договоры/_шаблоны/`. Фраза «подготовь допник для X по шаблону» → ИИ берёт шаблон отсюда, реквизиты — из карточки клиента, номер основного договора — из его карточки.

## Что ИИ здесь не делает
Не выдаёт документ как «готовый к подписанию» — только черновик, в конце документа блок «что проверить перед отправкой». Не берёт реквизиты по памяти — только из карточки. Не считает сроки от даты, которой нет в документе.

## На какие вопросы раздел отвечает
«Какие условия мы предлагали X?» · «Что подписано с X и когда истекает?» · «Сколько X должен по договору?» · «Все КП за квартал — что принято?»
