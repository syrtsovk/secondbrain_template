# Заготовки разделов

Из этих заготовок ИИ собирает разделы на шаге 2 установки и по фразе «заведи раздел …». В каждой папке два файла: `_правила.md` (как ведётся раздел — уровень 2 правил) и `карточка.md` (шаблон одной записи). При создании раздела ИИ копирует оба в `<Раздел>/`, подставляет ответы человека вместо `{{…}}` и добавляет строку в `ОГЛАВЛЕНИЕ.md`.

| Заготовка | Что ведём | Одна карточка = |
|---|---|---|
| Клиенты | кто нам платит или может заплатить | один клиент |
| Сотрудники | команда, подрядчики, договорённости с людьми | один человек |
| Планёрки | встречи команды, решения, задачи | одна встреча |
| Договоры | договоры, КП, допсоглашения, условия | один документ |
| Проекты | дела с началом и концом, этапы, статусы | один проект |
| Финансы | доходы, расходы, платежи, что кому должны | один месяц или один контрагент |
| Продукт | что продаём: описание, фичи, возражения, цены | одна фича или один продукт |
| Заметки | статьи, идеи, полезное — не про конкретного клиента | одна тема |

Нужен раздел, которого здесь нет (Поставщики, Аренда, Подопечные, Обучение…) — заготовка `раздел-с-нуля/`, ИИ задаст три вопроса и соберёт.
