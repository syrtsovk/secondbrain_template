# Шаблоны страниц `База/`

Шапка одна для всех (см. `AGENTS.md`), различается `type` и тело.

## Человек — `База/Люди/Имя Фамилия.md` (`type: человек`)
**Кто:** роль, компания [[…]] · **Как связан с нами:** … · **Контакт:** рабочий · **История:** снизу с датой · **Упоминается в:** [[…]]

## Компания — `База/Компании/Название.md` (`type: компания`)
**Чем занимается** · **Кто там** [[люди]] · **Наши отношения:** клиент / партнёр / конкурент / поставщик → ссылка на карточку раздела, если есть · **История** · **Упоминается в**

## Тема — `База/Темы/тема.md` (`type: тема`)
**Суть в 3 строках** · **Что мы про это знаем** (из каких источников, со ссылками) · **Что решили / как делаем** · **Открытые вопросы** · **Связано**

## Разбор источника — `База/Разборы/ГГГГ-ММ-ДД-тема.md` (`type: разбор`, `sources: [Сырьё/Источники/…]`)
**Что это** (статья / документ / письмо, откуда, дата) · **Главное — 3–7 пунктов** · **Что важно для нас** · **Цитаты** (дословно) · **Связано** [[люди, компании, темы, карточки]]

## Вывод — `База/Выводы/ГГГГ-ММ-ДД-тема.md` (`type: вывод`, `sources: [страницы, на которых основан]`)
**Вопрос** · **Ответ** с цитатами `[[…]]` · **На чём основано** · **Чего не хватает** · для итогов недели: **появилось · решили · висит · дальше**
