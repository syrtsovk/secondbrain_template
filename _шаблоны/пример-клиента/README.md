# Пример: как выглядит клиент в базе

Вымышленный клиент «ООО Ромашка», чтобы было видно, как связаны три файла: сырьё → разбор созвона → карточка клиента. ИИ использует его как образец, когда заводит настоящие карточки. На шаге 4 установки на нём можно попробовать первый вопрос: «что мы обещали Ромашке?».

После первого своего клиента пример не нужен — скажи «удали пример Ромашки».

| Файл | Что это | Где лежал бы в настоящей базе |
|---|---|---|
| `сырьё — 2026-09-10-созвон-ромашка.md` | транскрипт созвона как пришёл | `Сырьё/Источники/2026-09-10-созвон-ромашка.md` |
| `созвон — 2026-09-10 Ромашка.md` | разбор созвона: решения, договорённости, задачи | `Клиенты/ООО Ромашка/` или `Планёрки/` — по правилам раздела |
| `карточка — ООО Ромашка.md` | карточка клиента, обновлённая после созвона | `Клиенты/ООО Ромашка.md` |
