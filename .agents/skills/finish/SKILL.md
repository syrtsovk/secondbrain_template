# Конец сессии

Зафиксировать сделанное так, чтобы следующая сессия — твоя или с телефона — знала, где вы. Команды не показывать.

Первая строка ответа: `**Задача: ОБЫЧНАЯ** — завершение сессии · **Умение:** finish · **Правила:** AGENTS`.

## Шаги

1. **Что сделано.** `git status --porcelain` + что помнишь по этой сессии. Пусто и ничего не делали → «Сохранять нечего, всё уже зафиксировано» — и на этом всё.
2. **Проверка на запрещённое — не пропускать.** Пройди по изменённым файлам: паспорта, СНИЛС, медицинские документы, домашние адреса и личные телефоны людей, пароли, ключи, `.env`. Нашёл → **стоп**, ничего не отправляй: объясни, почему нельзя, предложи убрать в `_личное/` или вычистить. Отправленное однажды остаётся в истории.
3. **Три следа** у каждой созданной или изменённой страницы: (1) файл открыт и прочитан после записи; (2) новая страница есть строкой в `ОГЛАВЛЕНИЕ.md`; (3) операция есть строкой в `ЖУРНАЛ.md` → «Хронология». Чего-то нет — сделай сейчас. Шапка на месте, даты `ГГГГ-ММ-ДД`, `updated` — сегодня.
4. **`СЕЙЧАС.md`** — перепиши (это не лог, копить нельзя, ≤300 слов): «Где остановились (дата)» — 2–4 строки по смыслу · «В работе» · «Открытые вопросы» · «Следующий шаг». Закрытое — убери (оно уже в журнале).
5. **`ЖУРНАЛ.md`** → «Хронология» снизу: `## [ГГГГ-ММ-ДД ЧЧ:ММ] сессия | о чём была` + 1–3 строки: что сделано, ссылки `[[ ]]`. Если в сессии человек сказал что-то, чего в файлах нет, и это уже второй раз, — предложи запись в «Что поняли».
6. **Бэкап раз в неделю — сам, без вопросов.** Открой `_настройки-ИИ/_откуда.json`: файла нет или поле «дата» старше 7 дней → выполни умение `backup`, шаги 1–3 (копия настроек ИИ, следы). Остановился на находке — не страшно: база сохраняется дальше, вопрос уже в `СЕЙЧАС.md`. Облако и коммит — общие, на следующих шагах.
7. **Зафиксировать.** `git add -A && git commit -m "<по-русски, про смысл: Ромашка — созвон 10.09 и договор на этап 1>"`. Не «обновил файлы».
8. **Облако.** `git remote` не пустой → `git pull --rebase && git push`. Отбилось — повтори раз. Конфликт → показать оба варианта, спросить, не выбирать самому. Не сливается и терять нельзя → `git branch spasenie/<дата> && git push -u origin spasenie/<дата>` и объясни: «работа сохранена в отдельном месте, ничего не потеряно».
9. **Отчёт** одной-двумя строками: «Записал: … Облако обновлено / облако не подключено. В следующий раз начнём с …». Был бэкап → добавь: «И сделал недельный бэкап — если компьютер умрёт, всё вернётся».

## Чего не делать

- **Никогда `git push --force`.** Не откатывать чужие изменения. Не создавать веток, кроме аварийных.
- Не отправлять, пропустив шаг 2.
- Не писать в `СЕЙЧАС.md` больше, чем нужно, чтобы продолжить: это карта, не архив.
