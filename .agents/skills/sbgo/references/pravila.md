# Проверить правила для ИИ

`AGENTS.md` — правила, которые ИИ читает в начале каждого разговора. Чем он длиннее, тем хуже ИИ их держит: середину длинного файла он молча пропускает. Плохие правила хуже, чем никаких. Задача — держать файл коротким и точным.

Первая строка ответа: `**Задача: ОБЫЧНАЯ** — проверка правил · **Умение:** sbgo → pravila · **Правила:** AGENTS`.

## Чек-лист

| # | Проверка | Как | Норма |
|---|---|---|---|
| 1 | Длина | `python3 _скрипты/proverka.py` пишет число слов | ≤ 900 слов |
| 2 | Заглушки | нет `{{…}}` в блоке вверху | 0 |
| 3 | Временное | нет «сейчас делаем…», «на этой неделе…», имён текущих задач | 0 — временное живёт в `СЕЙЧАС.md` |
| 4 | Процедуры | нет пошаговых инструкций длиннее 3 строк | шаги — в умениях, здесь одна строка «когда → какое умение» |
| 5 | Повторы | правило не дублирует умение, `_правила.md` раздела или `МЕТОДОЛОГИЯ.md` | одно правило — одно место |
| 6 | Голые запреты | у каждого «не делай» есть «а как надо» | «не X — делай Y» |
| 7 | Общие слова | нет «будь внимателен», «пиши качественно», «думай шаг за шагом» | 0 |
| 8 | Крик | нет КАПСА, «!!!», «КРИТИЧНО» | 0 — от крика ИИ осторожничает во всём |
| 9 | Секреты | нет паролей, ключей, номеров документов | 0 |
| 10 | Свои правила | правила человека — в блоке вверху и в «Как база умнеет», не размазаны по файлу | одно место |

## Шаги

1. Пройди чек-лист. Покажи человеку таблицу ✓/✗, по каждому ✗ — одна строка: что не так и что предлагаешь («правило про счета повторяет `Финансы/_правила.md` — убрать отсюда»).
2. Длиннее нормы → предложи, что перенести: процедуру — в умение (`0-Начало/7-свои-умения.md`), правило раздела — в `<Раздел>/_правила.md`, временное — в `СЕЙЧАС.md`, устаревшее — убрать. Новое правило добавили → одно старое убрать или перенести.
3. После «ок» — правь точечно, не переписывай файл целиком. Блок про бизнес человека, строку-маркер ответа и блок «Готово» не трогай.
4. Открой файл, перечитай. `ЖУРНАЛ.md` → `## [ГГГГ-ММ-ДД ЧЧ:ММ] проверка | правила: было N слов → стало M`. Блок «Готово».

## Откуда правило попадает в файл

Только когда одна и та же ошибка или просьба повторилась **второй раз**. Не «на всякий случай» заранее — такие правила копятся и вытесняют нужные.
