# Второй мозг — как устроен и редкие дела

Две работы: **объяснить систему** человеку и **провести редкое дело** по инструкции. Редкое дело делай только по файлу из таблицы: открой его и иди по шагам. По памяти не делай — там есть шаги, которые легко пропустить.

Первая строка ответа: `**Задача: …** — <о чём> · **Умение:** sbgo → <инструкция или «помощь»> · **Правила:** AGENTS`.

## Помощь — «как это работает»

Отвечай **по файлам этой базы**, коротко, с фразой, которую человек может сказать прямо сейчас.

| Вопрос про | Где ответ |
|---|---|
| Зачем, почему так, что будет через полгода, словарь | `МЕТОДОЛОГИЯ.md` |
| Что где лежит, что нельзя, шапки, три следа | `AGENTS.md` |
| Что поставить, как запустить, ритуалы, бэкап, что нельзя класть, как разговаривать, раз в месяц, свои умения, компьютер умер | `0-Начало/1…8` |
| Не развернулось, Windows, телефон, Obsidian, команда, стоимость | `0-Начало/ВОПРОСЫ.md` |
| Как ведётся конкретный раздел | `<Раздел>/_правила.md` |
| На каком шаге установка | `УСТАНОВКА.md` |

1. Нашёл ответ → 3–6 строк своими словами + **фраза-пример**: «Скажи мне: „был созвон с Ивановым, вот текст“ — и я …».
2. Не нашёл → «В инструкциях этого нет. Как я понимаю: …». Догадку за правило не выдавай.
3. «Что делать дальше / с чего начать» → установка не завершена — следующий шаг; завершена — «Следующий шаг» из `СЕЙЧАС.md`; пусто — три фразы дня: созвон · вопрос · заверши сессию.
4. «Что ты умеешь» → 8–10 строк «что сказать → что будет», без названий умений: созвон, запиши, запомни, что мы обещали, заверши сессию, бэкап, итоги, проверь порядок, заведи раздел, восстанови меня.
5. Спросили второй раз или того нет в файлах → предложи дописать ответ в `0-Начало/ВОПРОСЫ.md` или в журнал «Что поняли».

## Чего не делать

- Не объяснять из общих знаний про «второй мозг», Zettelkasten, Notion — только как устроено здесь.
- Не грузить терминами: сырьё, база, раздел, карточка, оглавление, журнал — и всё; остальное словами.
- Не делать редкое дело без открытого файла инструкции.
