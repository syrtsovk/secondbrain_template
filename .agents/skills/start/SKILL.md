# Начало сессии

Человек сел работать. До ответа на его сообщение — привести базу в актуальное состояние и сказать в двух строках, где вы. Команды не показывать, выполнять самому.

## Шаги

1. **Установка.** Открой `УСТАНОВКА.md`. `status` не «завершена» → первая фраза ответа: «Установка на шаге N из 5, следующий — шаг N+1. Скажи „шаг N+1“, когда будешь готов» — и дальше отвечай на то, что человек написал. Если он сам сказал «шаг N» или «продолжим установку» → умение `ustanovka`.
2. **Незакрытое с прошлого раза.** `git status --porcelain`. Есть строки → с прошлого раза остались несохранённые изменения. Скажи, что именно, по смыслу («карточка Ромашки и разбор статьи»), и зафиксируй: `git add -A && git commit -m "Незакрытое с прошлого раза"`. Не пропускай — обновление поверх несохранённого теряет работу.
3. **Облако.** `git remote` не пустой → `git pull --rebase`. Конфликт → не выбирай сам, чью версию оставить: покажи оба варианта обычным текстом и спроси. Не понял человек — `git rebase --abort`, скажи, что ничего не потеряно.
4. **Где остановились.** Прочитай `СЕЙЧАС.md`. Возраст «Где остановились» больше 14 дней → отметь: «Последняя запись — <дата>, давно; если что-то было в промежутке, расскажи — запишу».
5. **Проверка порядка.** В `ЖУРНАЛ.md` найди последнюю запись типа `проверка`. Нет или старше 30 дней → одна строка: «Проверки порядка не было больше месяца — скажи „проверь порядок“, когда будет 15 минут».
6. **Скажи** — две-три строки, без путей и без слова «коммит»: где остановились · что висит (из «В работе» и «Открытые вопросы») · что предлагаешь первым. Потом — ответ на сообщение человека.

## Чего не делать

- Не пропускать шаг 2 ради скорости.
- Не делать `git reset --hard`, `git checkout --ours/--theirs` без выбора человека.
- Не пересказывать весь `СЕЙЧАС.md` — только живое.
