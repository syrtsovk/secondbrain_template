# Умения ИИ

Каждая папка — одно умение: файл `SKILL.md` с инструкцией, что делать по шагам. Агент (Cursor, Codex, Claude Code, Gemini CLI) подхватывает их при запуске и срабатывает по словам из описания — слэш-команды не нужны. Что сказать — в `0-Начало/5-как-разговаривать.md`; какое умение когда — в `AGENTS.md`, раздел «Сессия и умения».

| Умение | Откуда |
|---|---|
| `finish`, `backup`, `sozvon`, `zapisi`, `mysl` | написаны для этого шаблона: то, что делается каждый день или само. Начало разговора — не умение, а программа `_скрипты/start.py`: запускается сама |
| `sbgo` | написан для этого шаблона: объясняет систему; редкие дела (установка, раздел, итоги, проверка порядка и правил, обновление, восстановление) — в `sbgo/references/` |
| `promptmaker` | перенесён из проекта автора (v4.0); в описание добавлены разговорные триггеры |

Свои умения — сюда же, по `0-Начало/7-свои-умения.md`. Обновление из шаблона — по `0-Начало/ВОПРОСЫ.md` («Как обновить умения»).
