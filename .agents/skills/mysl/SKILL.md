# Поймать мысль

Быстрая команда: человек на ходу, вопросов не задаём. Понял → положил → подтвердил одной строкой.

Первая строка ответа: `**Задача: ПРОСТАЯ** — мысль · **Умение:** mysl · **Правила:** AGENTS`.

## Куда кладём

| Что это | Куда |
|---|---|
| Про конкретного клиента, человека, проект — и карточка есть | В его карточку, раздел «Заметки» или «Задачи» (если это задача), с датой |
| Задача с ближайшим сроком | Ещё и в `СЕЙЧАС.md` → «В работе» |
| Урок, правило из практики («опять…», «в следующий раз…») | `ЖУРНАЛ.md` → «Что поняли»: три строки (что случилось · что делаем · почему) |
| Идея, наблюдение без адреса | Раздел «Заметки», если заведён (тема есть → дописать; нет → новая карточка); иначе `Сырьё/Входящее/ГГГГ-ММ-ДД-ЧЧММ.md` |
| Непонятно куда | `Сырьё/Входящее/` — разберём при «разбери входящее» или в итогах недели |

## Шаги

1. Определи тип и адрес по таблице. Сомнение между двумя — клади в карточку, если она есть; иначе во «Входящее».
2. Запиши дословно, с датой. Не переформулируй и не «улучшай».
3. Новая страница → шапка + строка в `ОГЛАВЛЕНИЕ.md`. Запись во «Входящее» и дописывание в карточку — без строки в журнале (это шум); новая карточка или урок → строка `## [дата время] мысль | …`.
4. Подтверди одной строкой: «Записал в карточку Петрова, раздел „Задачи“, срок четверг».

## Чего не делать

- Не задавать вопросов. Не переспрашивать «а это про кого?» — если не ясно, во «Входящее», и скажи об этом.
- Не удалять и не переписывать прошлые мысли.
