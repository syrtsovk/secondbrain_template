# Созвон → карточки, договорённости, задачи

Одной фразой человека — обновлённая база: кто что обещал, кто что должен, что дальше. Без пересказа с его стороны.

Первая строка ответа: `**Задача: ОБЫЧНАЯ** — созвон с <кем> · **Умение:** sozvon · **Правила:** AGENTS + <Раздел>`.

## Шаги

1. **Взять текст.** Из сообщения, из файла, из вставленного транскрипта. Текста нет, только пересказ → работай с пересказом, но каждую цифру и срок помечай «со слов, <дата>». Нет ничего → попроси: «Пришли текст — расшифровку Zoom/Meet, из бота транскрибации или своими словами».
2. **С кем и куда.** Клиент → раздел «Клиенты»; команда → «Планёрки» (+ карточки людей в «Сотрудники»); партнёр/поставщик → свой раздел, если заведён, иначе `База/Компании/`. Прочитай `_правила.md` раздела. Раздела нет → предложи «заведи раздел …» или положи в `База/`.
3. **Найди существующее.** `grep -ri "<имя>"` по базе — карточка клиента/человека уже есть? Есть → обновляй её. Нет → создашь по `_шаблон-карточки.md` раздела.
4. **Извлеки:** участники · **решения** («решили X, потому что Y») · **договорённости** (кто, что, к какому сроку — таблицей) · **задачи** (исполнитель, срок; не ясно, кто взял → «не назначено ⚠️») · **открытые вопросы** · **следующий шаг** · **цифры и даты дословно** (кто сказал).
5. **Превью человеку** — списком, как выше, плюс «куда положу»: карточка встречи, что изменится в карточке клиента/людей. Ждать «ок» и уточнений (имена, сроки). Не писать до «ок».
6. **После «ок»:**
   - оригинал → `Сырьё/Источники/ГГГГ-ММ-ДД-созвон-<кто>.md` с шапкой (`author: человек`, `sources: [откуда]`); не редактировать;
   - карточка встречи → по правилам раздела (обычно `<Раздел>/ГГГГ-ММ-ДД созвон <кто>.md`), `sources:` — ссылка на сырьё;
   - карточка клиента/проекта: «Что обещали мы», «Что должны нам», «История» (снизу с датой), «Задачи», «Следующий шаг», статус — если есть основание;
   - карточки людей (если раздел «Сотрудники» есть): договорённости, задачи в работе;
   - ближайшие задачи и открытые вопросы → `СЕЙЧАС.md`;
   - `ОГЛАВЛЕНИЕ.md` — новые страницы; `ЖУРНАЛ.md` → `## [дата время] созвон | <кто> — <о чём>`.
7. **Открой** каждый изменённый файл, перечитай. Блок «Готово»: что сделал · где лежит · следы ✓ · что дальше. Закончи: «Скажи „заверши сессию“ — и я всё зафиксирую».

## Чего не делать

- Не выдумывать имена, суммы, сроки, которых не было. Не «улучшать» формулировки договорённостей.
- Не терять открытые вопросы — они переносятся, пока не закрыты.
- Не менять статус клиента/проекта без прямого основания в разговоре.
- Не создавать вторую карточку на того же человека под другим написанием имени.
