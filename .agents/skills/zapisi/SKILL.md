# Записать источник

Поймать ценное так, чтобы оно связалось со всем остальным, а не легло мёртвым грузом.

Первая строка ответа: `**Задача: ОБЫЧНАЯ** — запись: <что> · **Умение:** zapisi · **Правила:** AGENTS`.

## Шаги

1. **Прочитай целиком.** Ссылка → открой; файл → прочитай; pdf/картинка → в `Сырьё/Файлы/` + текст, если извлекается.
2. **Определи тип.** Транскрипт разговора → передай умению `sozvon`. Про конкретного клиента, договор, проект — и такой раздел заведён → карточка в разделе по его `_правила.md`. Иначе → статья/материал: разбор в `База/Разборы/`, сущности — в `База/Люди|Компании|Темы/`.
3. **Найди существующее.** `grep -ri` по ключевым именам и теме: страница про эту компанию/тему уже есть? Есть → дополняй, не дублируй.
4. **Превью человеку:** суть в 3–5 строках · куда положу · какие существующие страницы затрону · что связать. Ждать «ок».
5. **После «ок»:**
   - копия оригинала → `Сырьё/Источники/ГГГГ-ММ-ДД-<тема>.md` (шапка: `author: человек`, `sources: [откуда: ссылка/файл]`) — не редактировать;
   - разбор → `База/Разборы/ГГГГ-ММ-ДД-<тема>.md` по `_шаблоны/страница-базы.md`: что это · главное 3–7 пунктов · что важно для нас · цитаты дословно · связано; `sources:` → сырьё;
   - или карточка в разделе по его шаблону;
   - страницы людей/компаний/тем: создать или дописать «Упоминается в» / «История»;
   - `ОГЛАВЛЕНИЕ.md` — новые страницы; `ЖУРНАЛ.md` → `## [дата время] запись | <что>`.
6. **Открой** созданное, перечитай. Блок «Готово». Если материал спорный или сомневаешься в выводе — пометь «предположительно» в тексте.

## Чего не делать

- Не писать без превью. Не редактировать старое в `Сырьё/`.
- Не дампить чат или переписку целиком в `База/` — база это разбор, не лог; лог живёт в сырье.
- Не выдумывать связи: ссылка только на страницу, которая реально существует и реально связана.
- Много источников сразу («вот 10 ссылок») → по одному, с превью на каждый; можно короче, но не молча.
