# Спросить базу

Ответ по всему, что накоплено, — с цитатами, а не пересказом. Нет в базе — так и сказать.

Первая строка ответа: `**Задача: ПРОСТАЯ / ОБЫЧНАЯ** — вопрос: <о чём> · **Умение:** sprosi · **Правила:** AGENTS`.

## Шаги

1. **Оглавление первым.** `ОГЛАВЛЕНИЕ.md` → какие страницы могут содержать ответ (карточка клиента, раздел, тема). Дальше `СЕЙЧАС.md`, если вопрос про текущее. Потом — только нужные страницы, целиком не читать всё подряд.
2. **Поиск по слову** (`grep -ri "<имя/тема>"`) — когда по оглавлению не нашёл или имя написано иначе. Нашёл в сырье → вернись к карточке: одиночная фраза из транскрипта без контекста читается неправильно.
3. **Ответ:** суть в 2–4 строках → **цитаты дословно** с указанием страницы `[[карточка]]` и даты → если есть расхождения между страницами, покажи оба варианта и даты. Вопрос про «что обещали / что должны» → таблицей: что · кто · срок · откуда.
4. **Нет в базе** → «В базе этого нет. Смотрел: карточка X, планёрки за сентябрь, входящее». Не додумывай из общих знаний; если можешь предположить — отдельной строкой со словом «предположительно».
5. **Ответ полезен надолго** (сводка по клиенту, разбор темы, сравнение) → предложи: «Сохранить как страницу? Скажи „сохрани ответ“» → `База/Выводы/ГГГГ-ММ-ДД-<тема>.md` (`type: вывод`, `sources:` — страницы, на которых основан) + `ОГЛАВЛЕНИЕ.md` + `ЖУРНАЛ.md` → `вопрос | …`.
6. Устарело или противоречиво (даты старше, статусы разные) → скажи об этом: «Последняя запись — июль; если с тех пор что-то было, расскажи — обновлю».

## Чего не делать

- Не отвечать «нет такого», просмотрев часть папок.
- Не смешивать факт из базы и свою догадку без пометки.
- Не пересказывать вместо цитаты, когда цитата есть.
