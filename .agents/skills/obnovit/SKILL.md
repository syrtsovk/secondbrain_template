# Обновить из шаблона

Автор улучшает шаблон — умения, скрипт проверки, заготовки, инструкции. Твоя задача — подтянуть эти улучшения, **не тронув ничего, что принадлежит человеку**: его правила в `AGENTS.md`, разделы, карточки, журнал, свои умения, свои правки в перенесённых умениях.

Первая строка ответа: `**Задача: КРУПНАЯ** — обновление из шаблона · **Умение:** obnovit · **Правила:** AGENTS`.

## Что обновляется, а что нет

| Обновляется из шаблона | Не трогается никогда |
|---|---|
| `.agents/skills/<имя>/` — умения, которые есть в шаблоне | Умения, которых в шаблоне нет (свои) |
| `_скрипты/`, `_шаблоны/`, `0-Начало/`, `МЕТОДОЛОГИЯ.md`, `README.md`, `.gitignore` | `AGENTS.md` (там правила человека — только показать разницу и предложить точечно), `Сырьё/`, `База/`, разделы, `ЖУРНАЛ.md`, `СЕЙЧАС.md`, `ОГЛАВЛЕНИЕ.md`, `УСТАНОВКА.md` (кроме поля `template_version`), `_личное/` |

## Шаги

1. **Своя версия.** `УСТАНОВКА.md` → поле `template_version` (короткий хеш коммита шаблона, с которого развёрнута база). Пусто → считай, что правок человека в файлах шаблона не было, и на шаге 4 спрашивай по каждому изменённому файлу.
2. **Свежий шаблон.** Во временную папку вне базы: `git clone --quiet https://github.com/syrtsovk/secondbrain_template <tmp>` (Windows — `$env:TEMP`). Новая версия: `git -C <tmp> rev-parse --short HEAD`. Совпадает со своей → «Обновлений нет, у тебя последняя версия» — удали `<tmp>`, на этом всё.
3. **Что изменилось.** `git -C <tmp> diff --stat <своя_версия> HEAD -- <обновляемые пути>` и список файлов `--name-status`. Переведи на человеческий, сгруппировав: **умения** (какие, что нового — прочитай diff и скажи суть: «созвон: теперь спрашивает про сроки отдельно»), **скрипт проверки**, **заготовки разделов**, **инструкции**, **методология**. Новые файлы — «добавится», удалённые в шаблоне — «автор убрал; у тебя останется, если скажешь оставить».
4. **Правки человека.** Для каждого изменённого файла сравни свою копию с версией шаблона `<своя_версия>` (`git -C <tmp> show <своя_версия>:<путь>` → во временный файл → `diff`). Совпадает → человек файл не трогал, можно обновлять без вопросов. Отличается → человек правил → **не перезаписывай**: покажи, что правил он и что меняет автор, предложи три варианта: взять новое · оставить своё · взять новое, а свои правки перенести (тогда перенеси сам и покажи результат).
5. **`AGENTS.md`.** Никогда не копировать целиком: там блок про бизнес человека. Покажи diff шаблонного `AGENTS.md` между версиями и предложи каждое изменение отдельно («автор добавил правило про …; добавить?»). Применяй точечно, `Edit`, не `Write`.
6. **Спроси «ок»** одним сообщением: список того, что обновится без вопросов + вопросы по файлам с правками + предложения по `AGENTS.md`.
7. **Примени** после «ок»: скопируй файлы из `<tmp>` по списку; для Claude Code с копией `.claude/skills` (Windows) — обнови и копию. `УСТАНОВКА.md` → `template_version: "<новая>"`, `updated:` сегодня. Удали `<tmp>`.
8. **Проверь**: `python3 _скрипты/proverka.py` — 0 красных. Открой одно обновлённое умение и убедись, что файл целый. `ЖУРНАЛ.md` → `## [дата время] сессия | обновление из шаблона <старая> → <новая>: <что>`. Коммит «Обновление из шаблона <новая>».
9. Блок «Готово»: что обновилось · что оставили своё · что появилось нового и как этим пользоваться (одна фраза-пример на новое умение). Напомни: если умения не подхватились — перезапустить агента.

## Чего не делать

- Не трогать содержимое базы и `AGENTS.md` целиком. Не удалять свои умения человека.
- Не перезаписывать файл, который человек правил, без его выбора.
- Не клонировать шаблон внутрь базы — только во временную папку, и удалить после.
- Не менять `template_version`, если обновление не применено.
