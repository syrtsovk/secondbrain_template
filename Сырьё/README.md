# Сырьё — как пришло

Здесь лежат оригиналы: транскрипты созвонов, присланные документы, статьи, заметки на ходу. **ИИ здесь ничего не редактирует** — это факт «что было», к нему всегда можно вернуться и перепроверить разбор.

| Папка | Что | Как называется файл |
|---|---|---|
| `Источники/` | транскрипты, статьи, письма, документы текстом | `ГГГГ-ММ-ДД-тема.md`, шапка с `author: человек` и `sources:` (откуда) |
| `Входящее/` | быстрые мысли на ходу («запомни: …»), которые ещё не разобраны | `ГГГГ-ММ-ДД-ЧЧММ.md` |
| `Файлы/` | pdf, картинки, аудио, docx | как есть; текст, если извлекается, — рядом в `Источники/` |

Раз в неделю: «разбери входящее» — ИИ пройдёт по `Входящее/` и предложит, что куда.
