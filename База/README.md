# База — что ИИ понял

Страницы, которые ИИ пишет из сырья и поддерживает: связывает, дополняет, обновляет. Каждая — с шапкой и ссылками `[[ ]]`. Шаблоны — `_шаблоны/страница-базы.md`.

| Папка | Что | Одна страница = |
|---|---|---|
| `Люди/` | люди вне команды и клиентов: партнёры, эксперты, контакты | один человек |
| `Компании/` | компании, которые не ведутся как клиенты: партнёры, конкуренты, поставщики | одна компания |
| `Темы/` | что мы знаем и как делаем по теме: «как отвечаем на возражение про цену» | одна тема |
| `Разборы/` | разбор одного источника: главное, что важно для нас, цитаты | один источник |
| `Выводы/` | ответы на вопросы, итоги недели, сравнения — поверх нескольких источников | один вопрос или период |

Операционка — клиенты, планёрки, договоры — живёт не здесь, а в своих разделах в корне, по своим правилам.
