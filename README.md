# Второй мозг на базе ИИ — шаблон

> **Агент, если человек дал тебе ссылку на этот репозиторий и сказал «го» / «давай запустим» / «разверни» — делай так:**
>
> 1. Склонируй репозиторий в папку, где тебя открыли: `git clone https://github.com/syrtsovk/secondbrain_template .` (папка не пустая → клонируй в подпапку `Второй мозг` и скажи человеку открыть проект там).
> 2. Открой и прочитай файл `.agents/skills/ustanovka/SKILL.md` — это инструкция установки. Выполняй её **по шагам, по одному за разговор**, отмечая прогресс в `УСТАНОВКА.md`.
> 3. Ничего не выдумывай за человека. Спрашивай. Отчитывайся простым языком.

---

## Что это

Папка, в которой ИИ сам раскладывает, связывает и обновляет твои рабочие знания — созвоны, клиентов, договорённости, решения, заметки, — а потом сам в неё ходит, когда ты ставишь задачу. Ты кладёшь сырьё. Он ведёт базу. Чем дольше пользуешься, тем умнее она становится.

Обычный чат с ИИ забывает всё после разговора, а один бесконечный чат тупеет, когда переполняется. Здесь по-другому: память лежит в файлах, у неё есть оглавление и правила, и любая нейросеть, которая умеет читать файлы, берёт оттуда ровно то, что нужно под задачу.

## Как поставить

Нужен ИИ-агент, который работает с файлами на твоём компьютере: **Codex**, **Cursor** или **Claude Code**. Обычный чат в браузере не подойдёт — ему нечем трогать папку.

1. Создай пустую папку — например, «Второй мозг». Не в «Загрузках» и не на рабочем столе: это надолго.
2. Открой в ней агента (Cursor: «Открыть папку»; Codex / Claude Code: запусти в этой папке).
3. Отправь ему ссылку на этот репозиторий и одно слово: **«го»**.
4. Дальше он ведёт сам — пятью шагами, по одному за разговор. Можно в разные дни. Прогресс он помнит.

Подробнее — в папке **[0-Начало](0-Начало/)**: что поставить, как разговаривать, два ритуала, что нельзя класть.

## Что где лежит

| Папка / файл | Что внутри |
|---|---|
| **`0-Начало/`** | Инструкции человеку. Прочитать один раз |
| **`Сырьё/`** | Как пришло: транскрипты, документы, заметки на ходу. ИИ здесь ничего не редактирует |
| **`База/`** | Что ИИ понял: люди, компании, темы, разборы, выводы. Каждая страница со связями |
| **`Клиенты/`, `Планёрки/`…** | Твои разделы — появляются на установке, под твой бизнес |
| **`_шаблоны/`** | Заготовки разделов и пример, из которых ИИ собирает твои |
| **`AGENTS.md`** | Правила всей базы для ИИ (уровень 1). Для Claude Code — `CLAUDE.md`, ссылка на него |
| **`МЕТОДОЛОГИЯ.md`** | Зачем всё так устроено и почему это не развалится через полгода |
| **`ОГЛАВЛЕНИЕ.md`** | Куда ИИ смотрит первым, чтобы не перечитывать всю базу |
| **`ЖУРНАЛ.md`** | Что и когда было сделано + что поняли на практике |
| **`СЕЙЧАС.md`** | Что в работе и где остановились в прошлый раз |
| **`УСТАНОВКА.md`** | Чеклист установки: какой шаг пройден |
| **`.agents/skills/`** | Умения ИИ: обработать созвон, записать источник, спросить базу, проверить порядок… |

## Что говорить ИИ

Своими словами, без команд. Он сам поймёт, какое умение взять.

| Скажи так | Что произойдёт |
|---|---|
| «Го» / «продолжим установку» / «шаг 2» | Установка по шагам |
| «Начинаем» | Подтянет свежее из облака, покажет, где остановились и что висит |
| «Был созвон с Ивановым, вот текст» | Обновит карточку, запишет договорённости, выделит задачи |
| «Запиши это» / «разбери статью» | Положит в сырьё, сделает разбор, свяжет с тем, что уже есть |
| «Запомни: …» | Поймает мысль за пять секунд и положит на место |
| «Что мы обещали Иванову?» | Ответит с цитатами из твоих же страниц. Нет в базе — скажет честно |
| «Заведи раздел Поставщики» | Новая папка с правилами и шаблоном карточки |
| «Проверь порядок» | Найдёт, что подпортилось: битые ссылки, забытые страницы, не те даты |
| «Итоги недели» | Что появилось, что решили, что висит, что делать дальше |
| «Как пользоваться?» / «Почему так?» | Объяснит по методологии и покажет фразу-пример |
| «Сохрани» | Проверит сделанное, запишет в журнал, отправит в облако |
