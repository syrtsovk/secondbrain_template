# 1. Что поставить на компьютер

> Делается один раз, минут пятнадцать. Если что-то не встало — не разбирайся сам, напиши [@syrtsovk](https://t.me/syrtsovk).

Нужны две вещи: **ИИ-агент, который умеет работать с файлами**, и **git** (программа, которая хранит историю изменений и отправляет базу в облако).

## ИИ-агент — любой один из трёх

| Агент | Кому подходит | Как поставить |
|---|---|---|
| **Cursor** | Тем, кто хочет окно с кнопками, а не чёрный терминал | Скачать с [cursor.com](https://cursor.com), установить как обычную программу. Внутри — режим «Agent» |
| **Codex** | Есть подписка ChatGPT | В Терминале: `curl -fsSL https://chatgpt.com/codex/install.sh \| sh` — или приложение Codex с [chatgpt.com/codex](https://chatgpt.com/codex) |
| **Claude Code** | Есть подписка Claude | В Терминале: `curl -fsSL https://claude.ai/install.sh \| bash` |

Все три читают одни и те же файлы правил из этой папки — база не привязана к агенту, можно менять.

Терминал — это программа с чёрным окном, куда вставляют строку и жмут Enter. На Маке — поиск по слову «Терминал», на Windows — «PowerShell». Пойдёт текст — это нормально, дождись, пока остановится.

## Git

Проверь, есть ли уже. В Терминале:

```
git --version
```

Ответило номером версии — всё на месте. Написало «команда не найдена» — скачай с [git-scm.com](https://git-scm.com/downloads) и установи, ничего не меняя в настройках. На Маке git обычно ставится сам вместе с первым запуском Терминала.

Назови себя один раз, чтобы в истории было видно, кто что менял:

```
git config --global user.name "Иванов Пётр"
git config --global user.email "ivanov@example.ru"
```

## Облако — можно потом

Приватная копия базы живёт на [github.com](https://github.com). Аккаунт бесплатный. Он понадобится на пятом шаге установки — можно завести тогда, а можно сейчас. Без облака база работает на этом компьютере полностью.
