# Частые вопросы

Не нашёл ответа — спроси агента: «как мне…?», «почему…?». Он отвечает по методологии и этим страницам. Или напиши [@syrtsovk](https://t.me/syrtsovk).

**Агент не видит умения — говорит, что не знает, что такое «созвон».**
Умения подхватываются при запуске. Закрой агента и открой снова в той же папке. Cursor: перезапусти окно. Не помогло — скажи: «прочитай `.agents/skills/sozvon/SKILL.md` и сделай по нему».

**У меня Claude Code, а правила в AGENTS.md.**
На установке агент сам делает файл `CLAUDE.md` с одной строкой `@AGENTS.md` (Claude Code подтягивает правила оттуда) и папку `.claude/skills`. Если нет — скажи «сделай CLAUDE.md со строкой @AGENTS.md и папку .claude/skills».

**Windows — что-то не работает.**
Три типичных места: (1) вместо `python3` на Windows — `python`; скажи агенту «у меня Windows» — он запустит правильно; (2) ссылки на файлы — агент делает копии, а не ссылки; (3) в терминале вместо русских букв «кракозябры» — это только вид, файлы целы; в PowerShell помогает `chcp 65001`. Git лучше ставить с [git-scm.com](https://git-scm.com/downloads) с настройками по умолчанию.

**Хочу смотреть базу глазами, не через агента.**
Поставь [Obsidian](https://obsidian.md) — бесплатная программа для таких папок. «Открыть папку как хранилище» → выбери папку базы. Связи `[[ ]]` станут кликабельными, будет граф. Необязательно: агент работает и без него.

**Хочу спрашивать базу с телефона.**
После пятого шага база лежит в GitHub. В приложении Claude или ChatGPT подключи GitHub (в настройках — «коннекторы» / «интеграции») и выбери свой репозиторий. Дальше спрашиваешь с телефона: «что мы обещали Иванову?» — он читает базу напрямую.

**Как убрать пример «ООО Ромашка»?**
Скажи «удали пример Ромашки». Он лежит в `_шаблоны/пример-клиента/` и нужен только чтобы показать, как выглядит карточка, — после первого своего клиента не нужен.

**Можно ли вести базу вдвоём / командой?**
Можно, через общий репозиторий в GitHub. Тогда каждому нужны два ритуала: «начинаем» (агент делает сам) и «заверши сессию». Если двое правили одно место — агент покажет оба варианта и спросит, какой оставить. Никогда не выбирает сам.

**Как обновить умения из шаблона, если автор что-то улучшил?**
Скажи агенту: **«обнови умения из шаблона»**. Он сравнит твою базу с новой версией (в `УСТАНОВКА.md` записано, с какой ты начинал), покажет, что изменилось — какие умения, скрипт проверки, инструкции, — и обновит по твоему выбору. Твои карточки, разделы, правила про бизнес и свои умения он не трогает; файл, который ты правил сам, не перезапишет без спроса.

**Что если агент что-то сломал?**
Если облако подключено — «откатись к последнему сохранению». Всё, что было отправлено фразой «заверши сессию», восстанавливается. Поэтому эту фразу и стоит говорить чаще.

**Сколько это стоит?**
Шаблон бесплатный. Платная — подписка на агента: Cursor, ChatGPT (для Codex) или Claude (для Claude Code), примерно 20 $ в месяц. GitHub бесплатный.

**Можно ли класть сюда личное, не про бизнес?**
Да — заведи раздел «Личное» или используй папку `_личное`, которая не уходит в облако. База — не только про бизнес.
