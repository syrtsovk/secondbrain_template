# 7. Свои умения под повторяющиеся задачи

Поработал неделю-две — и замечаешь: одни и те же задачи повторяются. Планёрка каждый понедельник. Созвон с клиентом — каждый раз одно и то же: договорённости, задачи, что дальше. Отчёт для партнёра раз в месяц.

Под такое делается **умение** — текстовая инструкция для ИИ: что делать по шагам, где брать данные, куда класть результат. Он читает её каждый раз, когда слышит нужные слова.

## Как сделать

Скажи агенту:

```
сделай умение, которое обрабатывает понедельничную планёрку: протокол, задачи по людям, решения в журнал
```

Он спросит три-четыре вещи (какие слова его запускают, что на входе, что на выходе, куда класть) и создаст папку в `.agents/skills/` с файлом инструкции. Дальше ты пишешь «планёрка прошла, вот текст» — и он уже знает, что делать.

## Что уже есть

| Умение | Запускается словами | Что делает |
|---|---|---|
| `sozvon` | «был созвон», «вот транскрипт», «планёрка прошла» | созвон → карточка, договорённости, задачи |
| `zapisi` | «запиши», «разбери», ссылка или документ | источник → сырьё → разбор → связи |
| `mysl` | «запомни», «мысль:», «не забыть» | мысль → на место за пять секунд |
| `start`, `finish` | автоматически / «заверши сессию» | ритуалы начала и конца |
| `backup` | «сделай бэкап», раз в неделю само | копия всего, без чего не продолжить на новом компьютере |
| `promptmaker` | «сделай мне помощника» | инструкция для ChatGPT / Claude под твою задачу |
| `sbgo` | «как пользоваться», «го», «заведи раздел», «итоги недели», «проверь порядок», «обнови умения», «восстанови меня» | объясняет систему и ведёт редкие дела по своим инструкциям |

Все умения лежат в `.agents/skills/` — их читают Cursor, Codex и Claude Code. Свои умения живут там же.

## Помощник для ChatGPT или Claude

Отдельная вещь: «сделай мне помощника, который пишет посты для нашего канала в нашем тоне». Агент задаст четыре-пять вопросов и выдаст готовую инструкцию — её вставляют в ChatGPT («создать GPT») или Claude («проект»). Один раз вставил — дальше работаешь, не объясняя заново.

## Что стоит знать

Умение работает хорошо на понятных повторяющихся задачах и плохо там, где каждый раз всё по-разному. Чем больше своих примеров в базе — тем лучше результат: умение берёт данные из базы, а не из головы ИИ.
