# 4. Что сюда нельзя класть

База уходит в облако и хранит историю: удалённый файл остаётся в истории, его можно достать. Поэтому есть вещи, которые сюда не попадают вообще.

## Нельзя

| Что | Почему |
|---|---|
| Паспорта, СНИЛС, ИНН людей (не компаний) | Персональные данные. Утечка — штраф тебе и беда человеку |
| Медицинские документы, справки | Особая категория, ещё строже |
| Домашние адреса и личные телефоны людей | Персональные данные |
| Пароли, ключи, доступы к почте, банку, кабинетам | Попадут в историю навсегда |
| Сканы карт, выписки по личным счетам | Финансовые данные людей |

## Можно

- Реквизиты компаний: название, ИНН, ОГРН, юридический адрес.
- Рабочие контакты: должность, рабочий телефон, рабочая почта.
- Переписку, договоры, КП, транскрипты созвонов — если в них нет лишнего из таблицы выше.
- Свои мысли, решения, планы, заметки.

## Если документ нужен, а в нём есть лишнее

1. **Убери лишнее** перед тем, как класть. Из договора в базе достаточно сути: с кем, о чём, сколько, до какого числа.
2. **Положи в папку `_личное`** в корне базы. Она есть на этом компьютере, но в облако не уходит никогда — агент это знает.

## Если уже положил по ошибке

Не удаляй сам — файл останется в истории. Скажи агенту «в базу попало лишнее, вот что» — он подскажет, как вычистить по-настоящему. Чем раньше, тем проще.

Агент сам проверяет это перед каждым «заверши сессию» и останавливается, если что-то нашёл.
